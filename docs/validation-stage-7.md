- API 参数校验、Top-K、权重、完整结果结构、缓存后的结果稳定性。
- 桌面和窄屏浏览器页面布局及一次完整检索流程。

## 已知边界

- 原合成基准规模为每只股票 360 个交易日；大规模历史库需在阶段 9 引入持久化索引/批量向量计算。
- 缓存是单进程内存缓存，API 多 worker 间不共享；修改行情文件后需重启服务以加载新数据。
- 真实数据源为 AKShare 1.19.1 的 Sina 日线端点，复权口径 qfq；Eastmoney 默认端点在本机受代理网络限制，本次没有使用 Eastmoney 数据。
- 数据文件存放于本地 `data/processed/` 并由 `.gitignore` 排除，不上传行情 CSV 或 manifest。更新后需重启应用加载新快照。
- 阶段六浏览器演示及固定真实快照上的 Top-20 排名/距离复现已完成；阶段七完整真实数据回归和桌面/窄屏布局验收仍待执行。
- CNN 尚未接入，结果目前只代表 ColProj 形状相似度，不代表投资预测或收益保证。
