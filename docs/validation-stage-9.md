# 阶段九验证报告

验证日期：2026-10-25

## 实现方式

阶段九首版没有引入 FAISS 或 HNSW，而是采用 SQLite 特征表和精确三尺度矩阵距离：

- `feature_versions`：记录索引版本、数据源哈希、配置、模型、维度、状态和样本数。
- `samples`：保存 `(symbol,date)` 和月线、周线、日线三组 float32 ColProj 向量。
- `return_labels`：保存基准收盘价及未来1、5、10、20日收益率。
- API 配置 `KLINE_INDEX_PATH` 后，自动使用离线索引；没有兼容索引时回退到原请求时扫描。
- 查询阶段仍按查询日期、同股禁运期、已加载股票池过滤，再按月线、周线、日线权重进行精确排序。

索引版本绑定以下参数：数据源哈希、月线20日聚合、周线5日聚合、日线20日窗口、64×64图像、64维 ColProj 和未来1/5/10/20日标签。参数或数据源不一致时不会静默复用旧索引。

## 200 只股票真实索引

构建命令：

```bash
.venv/bin/kline-build-colproj-index \
  --database data/processed/csmar_a_share_daily.sqlite3 \
  --index data/processed/colproj_stage9_200.sqlite3 \
  --limit 200 \
  --replace
```

结果：

| 有效样本数 | 321,571 |
| 向量组数 | 3 × 321,571 |

| 收益标签记录 | 321,571 |

构建过程使用 `INSERT OR REPLACE`，版本状态从 `building` 原子切换为 `ready`；相同版本再次运行时可以跳过已存在的样本，新增交易日只会补充受影响的新样本。

## 一致性验证

在固定合成数据上，离线索引与请求时实时扫描返回的 Top-K 股票、日期和排序一致；测试覆盖同股禁运期、未来标签完整性、版本兼容性和收益标签落库。

真实 CSMAR 200只股票索引以 `000002 / 2026-09-17` 为查询样本时：

- 候选样本数：321,385。
- 返回 Top-20。
- 离线距离计算耗时：约3.2秒。
- 加载200只股票行情耗时：约1.5秒。
- 索引与当前数据源哈希、64×64和64维 ColProj 配置兼容。

此前同样的200只股票使用请求时逐样本绘图扫描，在120秒超时窗口内未完成；离线索引已消除历史候选的重复图像渲染，性能瓶颈从特征生成转移到矩阵读取和距离计算。

## 当前限制

- 当前索引覆盖前200只股票，不代表全部5,428只股票已经完成特征生成。
- 索引文件和原始行情仍保留在本机 `data/processed/`，不提交到 GitHub。
- 目前采用精确矩阵距离，下一阶段需要在分批全市场回填时增加索引分片和合并策略。
- CSMAR 日行情表没有股票名称和行业字段，索引仍继承阶段八关于 ST 和金融业筛选口径的限制。
