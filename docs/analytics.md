# 阶段四收益分析说明

## 未来收益

对于历史样本 `(symbol, t)`，使用收盘价计算未来收益：

```text
return_n = close[t + n] / close[t] - 1
```

默认周期为：

```text
1、5、10、12、21 个交易日
```

这里的 `t + n` 指第 `n` 个未来交易日，不是自然日加 `n` 天。

## 结果结构

`analyze_matches` 会为每个相似样本生成：

- 相似度和排名。
- 基准收盘价。
- 各未来周期收益。
- 未来 12 个交易日对照图。

同时对每个收益周期生成：

- 样本数量。
- 平均收益。
- 中位数收益。
- 正收益比例。
- 最小值和最大值。
- `q10、q25、q75、q90` 分位数。
- 直方图分箱数据。
- Gaussian KDE 曲线数据。

所有统计结果都通过 `as_dict()` 转换为前端可直接消费的 JSON 结构。

## 空数据处理

没有相似样本时不会抛出统计异常，对应统计项返回：

- `mean = None`。
- `median = None`。
- `win_rate = None`。
- 空直方图。
- 空 KDE 曲线。

样本未来数据不足时会拒绝生成不完整标签，避免把缺失数据当成 0 收益。
