# 阶段 13 全市场重建质量审计

## 全量审计与正式切换

- 审计对象：本机正式 CSMAR A 股 SQLite 行情库；重建前先在隔离副本完成审计，再启用正式库中的独立重建价格列。
- 股票数：5,428。
- 日线记录数：9,074,433。
- 锚点策略：每只股票使用其最新可用原始收盘价作为锚点。
- 重建口径：按日收益率双向递推收盘价，再以重建收盘价/原始收盘价同比例缩放原始开、高、低价。

## 结果

- 5,428 只股票、9,074,433 条 OHLC 记录均成功生成重建价格。
- 缺失的递推收益率：0；非法收益率：0；OHLC 关系不满足项：0；非正重建价格：0。
- 390 条记录的缩放因子低于 0.1，集中在 300738（311 条）和 603871（79 条）。这类记录被记录为人工抽样复核项，不自动判为错误或直接剔除。
- 最小缩放因子约 0.07297，最大约 1.00005。
- 重建价格列哈希：`9f74379b82b75e581f0cd915ca7fd52b55d45c85991fb90236609f4eaadd5d94`。
- 正式索引快照哈希：`4cdf937ddeb4c34fefd5c1ad558a9cd3ded8086bc72d4f1c5a135b59a2128f35`。

## 正式切换结果

- 正式数据库活动价格口径已切换为每只股票以最新可用原始收盘价为锚点的收益率重建价格；原始 OHLC、收益率及前收盘价字段保持不变。
- ColProj 与 CNN 各 28 个分片均已重建或验证，分别覆盖 6,862,102 个样本；对应样本数逐分片一致，全部绑定索引快照哈希 `4cdf937ddeb4c34f` 开头且 `price_basis=reconstructed`。
- CNN 向量由现有 `cnn-stage11-v1` 检查点重新计算；此次没有重新训练 CNN 权重。
- 新分片逐个通过版本、价格口径和样本数检查后替换旧分片。为控制磁盘空间，旧索引未保留；需要回退时必须重新构建旧口径索引。
- 28 个分片的索引版本与价格口径已完成静态一致性检查；标准库测试 66 项通过。
- 本地 API 冒烟测试通过：健康接口报告 5,428 只股票、两种模型各 6,862,102 个样本、`price_basis=reconstructed`；ColProj 和 CNN 检索请求均返回 200 和 3 条结果。
