# 阶段 6 验证报告

## 验证范围

- 数据与样本窗口、OHLC 聚合、图像尺寸/稳定性、ColProj 特征和距离、未来收益与统计。
- 查询特征只使用查询日及之前的行情；改变查询日之后的数据不会改变查询向量。
- 排除查询样本，只使用查询日之前且未来标签完整的历史候选。
- API 参数校验、Top-K、权重、完整结果结构、缓存后的结果稳定性。
- 桌面和窄屏浏览器页面布局及一次完整检索流程。

数据：默认演示集，来源 SHA-256 `39c95587cd1f03221789cca9c90f76172afaa370e0d367afa0feaa7da6996284`；查询 `ALPHA / 2024-05-20`；300 个候选，返回 Top-20。

| 运行 | 命中 | 未命中 | 特征构建 | 距离排序 | 检索合计 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 冷缓存 | 0 | 301 | 199.726 ms | 3.018 ms | 202.745 ms |
| 热缓存 | 301 | 0 | 1.251 ms | 3.072 ms | 4.324 ms |

冷/热查询返回一致的 Top-20 排名和距离。耗时依赖运行设备和负载，应在目标数据集与部署环境重新运行，不作为固定 SLA。

## 已知边界

- 当前演示规模为每只股票 360 个交易日；大规模历史库需在阶段 8 引入持久化索引/批量向量计算。
- 缓存是单进程内存缓存，API 多 worker 间不共享；修改行情文件后需重启服务以加载新数据。
- CNN 尚未接入，结果目前只代表 ColProj 形状相似度，不代表投资预测或收益保证。
